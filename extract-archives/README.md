# extract-archives

Extract various archive formats (zip, tar, 7z, rar, gz, xz, bz2) with common options.

## 文件结构

- 仅包含 `SKILL.md`

## 安装

```bash
# 克隆仓库
git clone https://github.com/iris-YMY/hermes-skills.git

# 复制到 Hermes skills 目录
cp -r hermes-skills/extract-archives/ ~/.hermes/skills/
```

## 使用

安装后，Hermes Agent 会自动识别此 Skill。在对话中提及相关关键词即可触发。
