# image-analysis

图片分析：调用 qwen-vl-max 视觉模型，通过 vision_analyze 或 browser_vision 工具识别图片内容。

## 文件结构

- 仅包含 `SKILL.md`

## 安装

```bash
# 克隆仓库
git clone https://github.com/iris-YMY/hermes-skills.git

# 复制到 Hermes skills 目录
cp -r hermes-skills/image-analysis/ ~/.hermes/skills/
```

## 使用

安装后，Hermes Agent 会自动识别此 Skill。在对话中提及相关关键词即可触发。
