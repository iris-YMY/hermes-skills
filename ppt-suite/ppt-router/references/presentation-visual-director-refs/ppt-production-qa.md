# PPT 生产 QC 验收标准（ppt-production-qa）

PPT 生产交付前的 QC 验收门槛。Review 环节与生产方共用本文件：生产方（powerpoint / ppt-master）按此自检，review 环节（本 skill）按此验收。

## 验收模式（二选一）

- `editable-pptx`：ppt-master 产出的可编辑 PPTX。文字与计划内的对象可编辑；计划内的原生图表含内嵌工作簿
- `image-only`：整页 PNG 或纯图片 PPTX。不承诺对象级可编辑；每页 PPTX 只含一张整页图

## 通用放行门槛

### 1. 渲染与逐页检查

- 最终版本最后一次改动后重新渲染，逐页全尺寸检查（contact sheet 只能辅助，不能替代逐页）
- 确认无断行、孤儿行、重叠、遮挡、溢出、裁切、截断、缺字形、未解析占位符、图表标签不可读
- 页码顺序、页数、目录、页码、语言、标点、单位、时间范围内部一致

### 2. 排版与可读性

- 正文、表格文字、图表数据标签 ≥ 12pt（可编辑 PPTX）；页脚、引用、来源注可更小但须可读
- 原生文本框必须 `noAutofit`：不接受"溢出时收缩文字"（spAutoFit）或"形状随文字调整"（normAutofit）。文字保持声明字号，溢出靠布局解决，不靠自动缩
- 文本框内文字垂直居中（anchor=ctr），除非模板/视觉锁/品牌规范明确要求顶部或底部锚定。水平居中不满足此项
- 模板/品牌有更严标准时，从严

### 3. 视觉对齐

- 有已批准的图像草稿/视觉锁/模板/参考页时逐页对比
- 保留批准的内容、层级、调色板、排版、位置、间距、视觉关系。仅实现方式差异可接受，但不得改变含义或批准外观
- 每次有意偏差都要记录；未批准的重大偏差 = FAIL
- 无视觉锁时，对照批准的样式简报与生产合同，不得自造新参考

### 4. 数据与来源一致性

- 每个实质主张、数字、类别、系列、单位、时间周期、顺序、定义，对照批准的数据台账
- 图表值与可见标签必须用同一数据集；不接受"图看着对、工作簿数值不同"
- 保留蓝本要求的来源注与证据边界
- 无依据结论、编造事实、静默改定义、无法解释的来源不一致 = 阻断项

## 可编辑 PPTX 门槛

- 必要文字、表格、形状、重复元素按交付合同可编辑
- 每个计划内 native-chart 必须是真正的 PowerPoint 图表，不是图片/SVG 图形/组合形状
- 图表有内嵌工作簿，PowerPoint 的"编辑数据"路径可访问
- 工作簿的类别、系列名、数值、单位、顺序与批准数据集一致
- 非原生图表仅在例外理由已事先记录并批准时接受
- 有视觉锁时，渲染后逐页核对可编辑 PPTX 与视觉锁一致

## 纯图片门槛

- 每张源 PNG：批准宽高比、完整页面边界、足够分辨率、文字可读
- 若打包 PPTX：每页恰好一张整页图，不把任何可编辑对象伪装成可编辑
- 无裁切、拉伸、偏移、页码错配
- 打包 PPTX 渲染与接受的源 PNG 一致

## 首图试点门槛（多图可编辑 deck）

1. 首批图表释放前先查第一张生产就绪图
2. 要求：原生图表结构、内嵌工作簿、可编辑数据、源数据完全一致
3. 任一失败即 FAIL 退回生产方，不授权批量继续
4. 试点通过后，对最终 deck 每张图执行同样检查

## 失败与复检契约

- 每项失败报告：严重级（blocker|warning）/ 页面·对象 / 失败门槛 / 证据 / 所需修正 / 生产方 ppt-master / 生产格式（generate-pptx|fill-native-pptx|enhance-native-pptx|full-slide-image）/ 复检范围（受影响页·对象 | 受影响页+全 deck 回归）
- 任一 blocker = FAIL，阻断交付
- 修正后重新渲染，复检受影响页 + 可能受影响的 deck 级条件
- 已知缺陷不得标记为已接受，除非明确批准且不违背交付模式的书面例外

## QA 报告模板

- Mode / Artifact / Rendered pages checked / Visual-lock used / Source ledger used / Native charts checked / Approved exceptions / Blockers / Warnings / Status: PASS | PASS_WITH_APPROVED_EXCEPTIONS | FAIL
- 只有 PASS 或 PASS_WITH_APPROVED_EXCEPTIONS 允许交付
