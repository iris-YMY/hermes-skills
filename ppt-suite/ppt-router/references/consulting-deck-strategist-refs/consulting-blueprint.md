# Consulting blueprint

## Hypothesis ledger

| ID | Hypothesis or question | Evidence needed | Status | Decision implication |
|---|---|---|---|---|
| H1 |  |  | untested / supported / rejected |  |

Keep facts, calculations, assumptions, and scenarios distinct. Record the source, date, definition, unit, and calculation logic for every material external claim.

## Claim-evidence map

| Claim | Status | Supporting evidence | Evidence boundary | Page |
|---|---|---|---|---|
|  | fact / calculation / hypothesis / scenario / recommendation |  | What the evidence does not prove |  |

Reject visual choices that imply unsupported causality, precision, validation, or completeness.

## Page blueprint

Use one block per page:

```markdown
### Page N — <action title>
- Role: framing / evidence / synthesis / recommendation
- Claim status:
- Proof object: chart / comparison / decomposition / timeline / matrix / decision path
- Evidence:
- Evidence boundary:
- Dependency:
- Takeaway:
- Native chart: yes / documented exception / not applicable
```

Order pages by argument dependency, not discovery order. Draft the executive summary only after its supporting evidence pages are stable.

## Handoff to Presentations

Provide:

- settled page blueprint;
- source ledger and calculations;
- intended audience and decision;
- supplied template or brand assets;
- required editable objects;
- chart datasets, categories, series, values, units, and ordering;
- explicit evidence and design constraints.

Presentations remains authoritative for visual routing, implementation, rendering, overlap and overflow checks, template fidelity, source notes, and final PPTX delivery.

## Final argument QA

- Every page advances the decision logic.
- Every title states a conclusion rather than a topic.
- Every material claim is traceable or clearly labeled as unproven.
- No evidence is used beyond its valid boundary.
- Charts preserve definitions, units, categories, series, and ordering.
- The conclusion follows from the evidence pages without a logical jump.
