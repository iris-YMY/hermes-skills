# publish-skill-to-github

将 Hermes Skill 发布到 GitHub 仓库（公开/私有），含仓库创建、文档完善、安装脚本和验证。

## 文件结构

- `references/` — 子目录
- `scripts/` — 子目录

## 安装

```bash
# 克隆仓库
git clone https://github.com/iris-YMY/hermes-skills.git

# 复制到 Hermes skills 目录
cp -r hermes-skills/publish-skill-to-github/ ~/.hermes/skills/
```

## 使用

安装后，Hermes Agent 会自动识别此 Skill。在对话中提及相关关键词即可触发。
