# GitHub 网页版入门速查

## 核心概念

| 概念 | 含义 |
|------|------|
| Repository（仓库） | 一个项目的文件夹，网址格式 `github.com/用户名/仓库名` |
| Commit（提交） | 一次保存/修改记录，类似文档版本历史 |
| Branch（分支） | 平行世界，`main` 是正式版，其他分支用于实验 |
| Pull Request（PR） | "我改了东西，请审核后合进正式版" |
| Issue（议题） | 问题/建议/功能需求 |
| Fork | 复制一份到自己账号，改完可提 PR |
| Star ⭐ | 点赞/收藏 |

## 网页界面

**首页 github.com**
- 左侧：关注项目、最近动态
- 顶部搜索栏：搜代码、仓库、用户
- 右上角 `+`：创建仓库、Gist

**仓库页面**
- 上方：仓库名、Star 数、描述
- 中间：文件列表
- 右侧：About、Release、Contributors
- 标签页：Code / Issues / Pull requests / Actions / Wiki

**README.md** = 项目说明书，打开仓库看到的第一段介绍

## 常见操作

**创建仓库**: 右上角 `+` → New repository → 填名字、选公开/私有

**浏览代码**: 搜索框 → 点进仓库 → 点文件看内容 → Star 收藏

**提 Issue**: 进仓库 → Issues → New issue → 写标题+描述

**Fork**: 进仓库 → 右上角 Fork → 复制到你账号下

**下载代码**: 进仓库 → 绿色 Code → Download ZIP

## 搜索技巧

- `language:python stars:>1000` — Python 写的、超 1000 星
- `github.com/explore` — 发现热门项目
- `github.com/trending` — 最近最火的项目

## 常见疑问

**GitHub vs Git**: Git 是本地版本控制工具，GitHub 是基于 Git 的网页平台

**必须会写代码？**: 不是，Issue/Wiki/文档欢迎非技术参与

**公开 vs 私有**: 公开所有人可见；私有仅授权人可见（免费账户可建无限私有仓库）
