# daily-stock-analysis

LLM-powered A/H/US stock intelligent analysis system with multi-source data, real-time news, AI decision dashboards, and multi-channel push notifications via GitHub Actions.

## 文件结构

- `references/` — 子目录

## 安装

```bash
# 克隆仓库
git clone https://github.com/iris-YMY/hermes-skills.git

# 复制到 Hermes skills 目录
cp -r hermes-skills/daily-stock-analysis/ ~/.hermes/skills/
```

## 使用

安装后，Hermes Agent 会自动识别此 Skill。在对话中提及相关关键词即可触发。
