# 弹性支出分析框架

## 三层分类模型

### 第一层：刚性支出（Fixed）
无法轻易削减的必要开支。节流优先级最低。

| 分类 | 说明 |
|------|------|
| 家属消费 | 亲属卡/亲情卡，家庭固定支出 |
| 转账（固定部分） | 定期转账（需区分固定 vs 临时） |
| 保险 / 金融保险 | 保费类 |
| 充值缴费 | 话费、会员等固定订阅 |
| 爱车（车贷部分） | 仅车贷，不含加油保养 |

### 第二层：半弹性支出（Semi-Flexible）
必要但金额可调控。关注"超额"部分。

| 分类 | 弹性点 |
|------|--------|
| 餐饮 / 餐饮美食 | 必须吃，但档次可控 |
| 生活日用 / 日用百货 | 必须买，但品牌和频率可控 |
| 交通 / 交通出行 | 通勤必须，打车 vs 地铁有差价 |
| 宠物 | 口粮必须，零食玩具可控 |
| 医疗保健 / 医疗健康 | 看病必须，保健品可选 |
| 学习 | 课程/书籍，可推迟 |

### 第三层：高弹性支出（Highly Flexible）
完全可以推迟或取消。节流优先关注。

| 分类 | 说明 |
|------|------|
| 穿搭美容 / 服饰装扮 / 美容美发 | 最典型弹性支出 |
| 休闲玩乐 / 文化休闲 | 娱乐消费 |
| 人情社交 | 礼金社交（部分可控） |
| 购物 | 非必需品 |
| 运动 | 可选消费 |
| 酒店旅行 | 旅行消费 |
| 日常消费（大杂烩） | 需通过备注拆解后重新归类 |

## 计算公式

```
基准线 = 过去6个月该分类月支出的中位数
超额 = 当月实际 - 基准线（正=超支，负=节省）
弹性支出 = 高弹性支出总额 + 半弹性支出超额部分之和
弹性系数 = 弹性支出 / 总支出 × 100%
节流潜力 = 弹性支出 - 高弹性支出中位数（代表"正常弹性"部分）
```

## "日常消费"拆解规则

"日常消费"占比过大时（>30%），需通过备注关键词拆解：

| 备注关键词 | 重归类 |
|-----------|--------|
| 淘宝/天猫/京东/拼多多/抖音商城 | 购物 |
| 超市/盒马/山姆/Costco | 生活日用 |
| 美团/饿了么/外卖 | 餐饮 |
| 滴滴/高德/打车 | 交通 |
| 电影/KTV/密室/剧本杀 | 休闲玩乐 |
| 医院/药/诊所 | 医疗保健 |

## 节流建议输出模板

```
【本月弹性支出】¥X,XXX（弹性系数 XX%）
【Top 3 节流空间】
1. [分类名] 本月 ¥X,XXX vs 基准 ¥X,XXX（+XX%）→ 建议：[具体措施]
2. ...
3. ...
【高弹性趋势】近3个月高弹性支出走势：[升/降/平]
```
