# personal-finance-dashboard

Merge Alipay + WeChat + Tencent Docs financial exports into unified data source and generate interactive HTML dashboard with charts.

## 文件结构

- `references/` — 子目录
- `scripts/` — 子目录

## 安装

```bash
# 克隆仓库
git clone https://github.com/iris-YMY/hermes-skills.git

# 复制到 Hermes skills 目录
cp -r hermes-skills/personal-finance-dashboard/ ~/.hermes/skills/
```

## 使用

安装后，Hermes Agent 会自动识别此 Skill。在对话中提及相关关键词即可触发。
