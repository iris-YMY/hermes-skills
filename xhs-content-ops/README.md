# xhs-content-ops

小红书全链路内容运营 SOP：数据获取 → 图文/视频拆解 → 账号诊断 → 笔记生成 → 知识沉淀 → 发布。

## 文件结构

- `references/` — 子目录
- `scripts/` — 子目录
- `templates/` — 子目录

## 安装

```bash
# 克隆仓库
git clone https://github.com/iris-YMY/hermes-skills.git

# 复制到 Hermes skills 目录
cp -r hermes-skills/xhs-content-ops/ ~/.hermes/skills/
```

## 使用

安装后，Hermes Agent 会自动识别此 Skill。在对话中提及相关关键词即可触发。
