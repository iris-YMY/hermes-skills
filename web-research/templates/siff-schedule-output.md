## 字段说明

| 字段 | 说明 |
|------|------|
| 日期行 | `📅 6月13日 周六（2场）` — 含当日场次数 |
| 时间范围 | `开始–结束`，散场时间 = 开始 + 时长 + 10分钟 |
| 影院行 | `影院名称 · 影厅`，用 `·` 分隔 |
| 状态 | `✅ 已购N张` 或 `⏳ 待抢` |
| 备注 | 可选，标注转场说明、餐饮建议等 |

## 截图解析注意事项

用户经常发送购票 App 截图作为数据源。解析时注意：
- 截图可能只显示部分信息（如片名被截断），需向用户确认缺失字段
- "已购2张"表示已完成购票，"抢票"按钮仍可购买额外票
- 同一天的多个场次需检查时间是否冲突
- 截图中的"散场时间"有时直接给出，无需计算
