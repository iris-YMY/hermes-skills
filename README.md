# hermes-skills

Private collection of custom skills for Hermes Agent.

## Installation

```bash
# Clone the repository
git clone https://github.com/iris-YMY/hermes-skills.git

# Copy a specific skill to Hermes skills directory
cp -r hermes-skills/<skill-name>/ ~/.hermes/skills/
```
