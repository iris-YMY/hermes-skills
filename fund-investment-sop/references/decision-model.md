# 四层决策模型

## 架构

```
第一层：宏观环境 → 现在适不适合投资？
第二层：行业板块 → 哪些行业有机会？
第三层：基金评估 → 这只基金好不好？
第四层：买卖时机 → 现在该买还是该卖？
```

## 第一层：宏观环境

| 数据 | 来源 | 信号 |
|------|------|------|
| 大盘指数 | 东方财富 | 连涨5天+情绪高→回调风险；连跌5天+恐慌→机会 |
| 政策动向 | 新闻搜索 | 政策利好→加仓；政策利空→观望 |

**局限**: 无宏观经济数据API（PMI/CPI等），依赖新闻搜索。

## 第二层：行业板块

| 数据 | 信号 |
|------|------|
| 行业涨跌幅 | 顺势而为 |
| PE百分位（需用户截图） | 低估加仓、高估减仓 |
| 政策方向 | 政策支持行业优先 |

## 第三层：五维评估

| 维度 | 权重 | 标准 | 数据源 |
|------|:---:|------|--------|
| 业绩 | 30% | 近3年同类前1/3 | AKShare fund_open_fund_rank_em |
| 费率 | 15% | 管理费+托管费<1.5% | 东方财富API |
| 基金经理 | 25% | 从业3年+，规模>10亿 | AKShare fund_manager_em |
| 持仓质量 | 20% | 行业分散，个股集中 | 东方财富pingzhongdata |
| 回撤控制 | 10% | 最大回撤<同类平均 | 本地计算 |

### 基金经理评估
- 任职3年+ + 规模>10亿 + 业绩前1/3 → 可信赖
- 经理刚上任<1年 → 观察期
- **经理更换 → 减仓观望**

|------|:---:|:-----:|

| 技术面 | 30% | 🟡 中 |

| 情绪/消息 | 10% | 🔴 低 |

## 加减仓触发规则

### 加仓
- 单只回撤>10% → 加仓10-20%
- 指数单日跌>2% → 紧急加仓5-10%
- PE<历史30% → 分批加仓
- **金字塔加仓**: 第1次1份→跌5%再2份→再跌5%再3份

### 减仓
- 盈利>30% → 减仓20-30%止盈
- 盈利>50% → 减仓30-40%止盈
- 基本面变差 → 减仓50%+或清仓

### 清仓
- 连续2季度排名后1/3
- 基金经理更换
- 规模<2亿（清盘风险）

## 投资纪律

### 禁止
1. 追涨杀跌
2. 单只基金超总资产30%
3. 7天内频繁操作（赎回费1.5%）
4. 同一天对同一基金既加仓又减仓

### 坚持
1. 分散投资
2. 长期持有（1年+）
3. 定期定额
4. 止盈不止损
5. 定期复盘
