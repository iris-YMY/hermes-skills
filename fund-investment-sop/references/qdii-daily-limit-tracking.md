## QDII 限额机制说明

- **限额原因**: QDII基金受外汇额度管控，部分热门QDII设置单日申购上限
- **限额金额**: 由基金公司/平台动态调整，可能从¥10变为¥100或暂停
- **限额恢复**: 基金公司获得新外汇额度后可能取消限额
- **交易日**: 仅周一至周五（A股交易日），节假日不交易

## 操作 SOP

### 每日提醒（已自动化）
- 每个交易日 14:30 播报中自动提醒
- 格式: `💱 {代码} {名称} — 买入 ¥{限额}（QDII每日限额，已买¥X/计划¥Y）`

### 用户操作流程
1. 打开蚂蚁财富 → 搜索基金代码
2. 买入当日限额金额（如¥10）
3. 告知 agent "000834 已买入¥10"
4. Agent 记录到 pending_transactions（T+1确认）

### Agent 记录流程
- 每次用户确认后，写入 portfolio.json pending_transactions
- 确认日后更新 holdings（新增金额和份额）
- 跟踪累计金额，更新 recommended_funds.json 进度

### 完成条件
- 累计买入金额 ≥ 计划总额 → status 改为 "completed"
- 用户主动说"不再买了" → status 改为 "cancelled"
- 限额取消/提高 → 可一次性补足差额

## 常见问题

**Q: 如果某天忘记买了怎么办？**
A: 第二天正常买当天的¥10即可，不需要补买。QDII限额是每天重置的。

**Q: 限额提高了怎么办？**
A: 如果限额提高到¥100/天，可以加快建仓速度，或一次性补足差额。

**Q: 限额取消了怎么办？**
A: 可以一次性买入剩余计划金额，加速完成建仓。
